# 实现约定

## 训练估计器

每轮先用三个独立 Python RNG 流生成完整候选索引、Bernoulli mask、回答随机种子。
重复题按位置独立生成；没有为了填满 GPU 强制增补抽中题。
本轮预测器由固定的示范集合、当前参数和预先校准的 a 决定。
先计算带符号的示范项，再对被抽中位置计算 RLOO 残差；整批只更新一次。
不把损失数值的期望与负成功率混为一谈；无偏结论针对采样参数处的梯度。

`objective.py` 包含纯数学系数与采样器，`train.py:update` 将同一公式落实到反向传播。
训练与生成都禁用 dropout，使用固定 raw-policy 分布。新建 GenerationConfig，避免从权重配置继承截断采样、重复惩罚或 forced-token 规则。
EOS 包含在序列得分里；首个 EOS 之后的批量 padding 不计入；截断回答保留实际 H 个 token。

## 数据范围

标准解答统一为完整推导加最终 boxed 数值。GSM8K 的计算器标注移除，保留推导文本。
MATH 使用现有项目的 `jeggers/competition_math` numeric 子集，不将其结果叫作完整 MATH benchmark。
训练候选在分割前按共同 prompt/H 限制筛选；绝不截断示范来保留部分答案。
测试题不因示范长度被筛掉；超长 prompt 仍按既定规则排除并记录。
训练、校准、审计、验证、测试按规范化题目 ID 去重并隔离。
这排除本次准备过程的直接重叠，不声称解决预训练污染或语义近重复。

## 梯度审计

所有范数和内积都在实际可训练 LoRA 参数的完整欧氏空间计算，不使用随机投影。
每道题得到示范方向 u 和两组独立、同样 G 的真实 RL 梯度 g1/g2。

```text
a = max(0, sum <u,(g1+g2)/2> / sum ||u||²)  # 仅校准题
epsilon_i = <g1-a*u, g2-a*u>                # 独立审计题
nu_i      = ||g1-g2||²/2
tau²      = mean_i <g1_i,g2_i>
            - sum_{i!=j}<g1_i,g2_j> / (n(n-1))
```

tau 使用不同题目的交叉项去掉总体均值平方，避免用带噪均值的平方代替。
这在独立题目模型下是题间方差估计；当前有限冻结子集相对于更大训练池仍有抽样误差。
每个 audit 只在磁盘暂存两个 RL 向量，逐题累计总和；二次读取计算 delete-one 统计后移除本次生成的向量文件，保留标量记录。
不会因为估计为负就伪造零方差；关键点估计为负时默认不启用 DiG。

成本是同一卡上测量的生成、前后向 wall time，加上审计开销摊销，不是理论 FLOPs。
以 `max_steps*candidates` 摊销审计只是一项计划假设；若时间预算提前截断，实际摊销更高。
最终结果另行计入审计全部秒数，不能只引用 gate 的预测收益比。
Jackknife 正态近似不覆盖所有重尾、GPU 时间漂移、校准不确定性和跨训练状态漂移。
它是运行筛选器，不能写成“已验证的数值证书”。

## 评估与成本

默认评估固定 final checkpoint，在 validation 上每题 4 条独立 raw-policy 回答，报告逐题平均成功率。
这估计 pass@1，不是 pass@4；不将回答总数当作独立题目数。
汇总脚本按题目配对给出 bootstrap 差异区间，只有一个训练种子时不能当作多种子结论。
test 应在配置与候选冻结后单独评估；默认启动器不会打开 test。

SGD lr=0.01、H/G/B、200 步上限是初始可复现 pilot 配置，并未由 GPU 实验调优。
必须查看梯度范数、真实参数更新、截断率和耗时，再决定下一轮配置。
当前工程不声称给出全程 L 或 Vmax 的证书，也不从 CPU 单测推断 H200 加速。
